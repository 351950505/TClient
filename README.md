# TClient 定制版

基于 [TClient](https://github.com/TaterClient/TClient)(DDNet 客户端)的个人定制版本,在原版基础上增加了一系列实用功能。

## 功能一览

### 上行自适应多发包(抗丢包)

- 检测到上行丢包时,自动将发出的游戏包多发几份(最多三份),服务器自动去重,链路恢复后自动降回单发
- 适合跨境连服:高丢包环境下能明显减少"打不动、回拉、瞬移"
- 设置 → TClient → 抗延迟工具 中有开关,可调错峰发包与间隔
- 丢包率、补救次数可在控制台查看

### 快速输入(共 11 种模式)

- 原有 7 种:Tater / Ancient / Next / Meow / Snow / Salatik / F
- 新增 4 种:Best / Saiko / Delta / Cloud
- 每种模式可独立调节预测量、钩锁逻辑、是否作用于其他玩家
- 设置 → TClient → 输入 中切换

### 灵动岛(音乐悬浮条)

- 屏幕顶部悬浮显示当前歌曲信息,仿 iOS 灵动岛样式
- 黑胶唱片样式封面:圆形封面嵌在黑胶唱片上,随播放缓慢旋转
- 歌词实时同步:支持逐字卡拉OK歌词,拖动播放进度条歌词即时跟随
- 暂停/恢复即时响应,歌名/歌手/专辑封面自动显示
- 支持网易云音乐、QQ 音乐等多种播放器
- 两种样式:悬浮胶囊 / 刘海贴合(贴屏幕顶部)
- 自动从网易云匹配歌词与封面,无需手动配置

### 其他

- TClient 设置界面全面中文化
- 双发等网络功能均已做成可视化开关,无需敲控制台命令

## 使用

- 直接运行编译好的客户端(需要配合本仓库源码自行编译,或使用发布的整合包)
- 所有新增功能都在 设置 → TClient 页面中
