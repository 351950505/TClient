# TClient 定制版

基于 [TClient](https://github.com/TaterClient/TClient)(DDNet 客户端分支)的定制版本。界面全中文,在原版基础上补了网络层增强、音乐灵动岛、一批可视化开关,以及一个能自己验签的自动更新器。

所有功能都在 **设置 → TClient** 里,不用敲控制台命令。

## 功能

### 网络与延迟

- **自适应上行多发包(抗丢包)**:检测到上行丢包时自动把包多发几份(最多三份),服务器自动去重,链路恢复后自动降回单发。跨境连服时能明显减少"打不动、回拉、瞬移"。
- **错峰发包**:副本之间拉开间隔,专门对付突发丢包,间隔可调。
- **抗延迟工具**:预测量、延迟补偿、冻结时禁用预测、被冻结时不预测其他玩家、冻结专用预测值。
- **平滑预测**:可选新平滑算法、稳定方向下的积极预测、延长网络波动判断时间、不确定性持续时间。
- **自适应快照插值缓冲(抗网络抖动)**:实时统计最近 64 个快照的到达间隔抖动,按 2×平均绝对偏差自动加一点渲染延迟(上限可调,默认 30ms),让早到/晚到的快照都落在缓冲里,画面不再跟着网络抖动抽搐。缓冲每次快照最多动 1ms,不会自己变成新的抖动源;网络平稳时按同样节奏收回。
- **快速输入(11 种模式)**:Tater / Ancient / Next / Meow / Snow / Salatik / F / Best / Saiko / Delta / Cloud。每种模式可独立调预测量、钩锁逻辑与数量,也可以只作用于自己、不作用于其他玩家。
- 丢包率与补救次数可在控制台查看。

### 灵动岛(音乐悬浮条)

- 屏幕顶部悬浮显示当前歌曲,三态分明:**播放**(黑胶唱片 + 封面旋转 + 逐字卡拉OK 歌词 + 进度条)、**暂停**(整体压暗,歌名与封面保留)、**停止/无歌**(只留对局计时和一枚待机唱片环)。
- 两种样式:悬浮胶囊 / 刘海贴合(贴屏幕顶部边缘);支持透明模式。
- 歌词与封面:网易云、QQ 音乐双源,逐字歌词实时同步,拖动播放进度歌词立刻跟上;封面走 CDN 缩略图并有本地缓存。
- 时钟:对局时间默认显示,本地电脑时间可选(12 小时制、可显示秒)。
- 外观可调:跟随全局字体、大小、水平/垂直偏移、边缘柔和度(投影)、胶囊渐变起点色与四角调色、歌词偏移与卡拉OK 提前量。

### 输入与操作

- **Ping 信号轮盘**:按住绑键选方向发信号,可调音量与可听距离。信号统一走 TClient 信令中继:活着与旁观都能发,不占用游戏服的聊天与表情;限频 5 秒内 5 次,超限冷却 60 秒。聊天里显示为图标而非文字。
- **绑定轮盘 / 聊天绑定**:可视化编辑按键轮盘与聊天快捷语句。
- **自动执行**:连接前、加入服务器时自动跑控制台命令(可设延迟)。
- **一键缩放**:按一下切到目标缩放,再按恢复。
- **自动投票**:挂机跑图太久时自动拒绝换图投票,可附一句聊天说明。
- **自动回复**:被禁言玩家私聊、以及切出游戏窗口时自动回一句。

### 界面与视觉

- **全中文界面**:除专业名词外,TClient 新增文案全部走 TCLocalize 词典,按钮标签也不例外,不是硬编码中文。
- **渐变**(移植自 BestClient):昵称、战队名、皮肤、以及没有显式颜色的全部文字可各自独立开启动画渐变。三种模式:跟随皮肤双色往返、自定义 2–4 色闭环、彩虹。范围可选只作用于自己、只作用于其他玩家或所有人;速度可调。0.6 与 0.7/Sixup 皮肤都支持。War 名单颜色、管理员色、同队高亮、聊天富文本等显式颜色优先,不会被渐变盖掉。
- **控制台分类筛选**(F1):顶栏「全部 / 玩家 / 系统 / 命令 / 绑定」五个标签,点一下只看该类别,再点回全部;Alt+1..5 同效。日志在写入时就分好类,不是事后猜。
- **客户端标识**:记分板在 TClient 玩家的分数列左侧画一枚企鹅。识别走 ddnet-custom-clients 的皮肤颜色标准,零额外服务器、零聊天消息,原版客户端无感知。**身份始终广播**,设置里只能关掉自己是否看到图标。
- **界面缩放 50%–200% + 全局字体大小 + 自定义字体**(可放字体文件到目录里直接选用)。
- **玩家相关**:玩家指示器(屏幕边缘箭头,可渲染成迷你 Tee、按敌对列表配色、按距离调偏移)、宠物、Tee 拖尾、彩虹 Tee/武器/钩索、打开设置菜单的玩家头顶显示齿轮、名称前延迟色圈与国旗、旁观时隐藏昵称。
- **场景相关**:方块轮廓(墙体/冷冻/解冻/即死/传送分色)、影子工具(显示未预测的影子)、背景绘制、HUD 增强(位置角度调试面板、屏幕中心线、最后存活提示、小型投票 HUD、观战光标)。「只剩一人」提示独立于灵动岛,灵动岛开着也会照常显示。
- **Tee 状态栏**:冻结玩家的状态一览,行数/Tee 尺寸/剩余数量可调。
- **状态栏**:自定义代码拼装(角度、延迟、预测、位置、本地时间、比赛时间、FPS、速度、缩放),颜色与透明度独立可调。
- **主播模式**:敏感词屏蔽(聊天/名字/战队)、非好友名字显示为编号并用默认皮肤、强制隐藏国旗,支持自定义屏蔽词文件。
- **消息屏蔽**:队伍聊天、私聊、系统消息、击杀信息、通关信息分别可关。

### 社交与信息

- **观战选择器好友分列**:好友单独分组并带标题排在最前,其余玩家紧随其后。
- **敌对列表(War List)**:条目 + 群组 + 颜色,聊天/记分板/旁观选择各自配色,支持从在线玩家直接添加。
- **素材编辑器**:游戏内直接替换 HUD、表情、粒子等素材,支持隐藏列表与还原。
- **玩家档案**:皮肤、颜色、表情、名称、战队、国旗各自保存/加载;Discord 集成显示当前状态。
- **自动翻译**:腾讯云 / 百度 / DeepL / MyMemory / LibreTranslate / 任意 OpenAI 兼容 LLM,可只翻其他玩家的非中文发言,也能翻自己发出的消息;支持按键翻译最近几条。
- **自定义社区**:从远端 JSON 拉取社区列表,地址可改。

### 更新

- **内建自动更新**:清单走 GitHub Releases,Ed25519 验签后才应用,helper 自举完成替换并重启;验签失败或下载中断会回滚。
- **双轨发布**:日常更新包只替换程序本体与 `data/tclient`(新功能文案、词典、图标),不碰 `data` 下的音效、皮肤、地图和你改过的配置;全量包给新装玩家。
- 更新不动配置、录像、自定义字体与玩家自己的资源。

## 使用

- 新装:下载 `TClient-v*-full-win64.zip` 解压即用。
- 已有客户端:交给自动更新即可,或手动下载 `TClient-update-win64.zip` 覆盖。
- 编译:与 DDNet 一致。本机验证用的是 **VS 2026 BuildTools**(MSVC 14.51)+ CMake:

  ```
  cmake -S . -B build-vs2026
  cmake --build build-vs2026 --config Release --target game-client TClientUpdater --parallel
  ```

  产物在 `build-vs2026/Release/`。跑单测需要把 `ddnet-libs/*/windows/lib64` 加进 `PATH`(缺 `libpng16-16.dll` 等),并在源码目录下执行 `testrunner.exe`(部分用例要读 `$DATADIR`)。
